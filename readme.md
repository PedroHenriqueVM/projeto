# Calculadoras Empresariais

**Descrição:**
Este projeto consiste em um conjunto de três aplicações web simples desenvolvidas para resolver problemas comuns de gestão empresarial.
As páginas permitem calcular **horas extras de funcionários**, **aumento salarial baseado em faixas de salário** e **custo de transporte de colaboradores**.

O objetivo do projeto é praticar conceitos básicos de **HTML, CSS e JavaScript**, além de desenvolver lógica de programação aplicada a situações reais do ambiente corporativo.

# Funcionalidades

### Exercício 1 – Cálculo de Horas Extras

* Inserir salário bruto do funcionário
* Informar horas extras em dias normais
* Informar horas extras em finais de semana
* Calcular automaticamente o valor total das horas extras

### Exercício 2 – Aumento de Salário

* Inserir o salário atual do funcionário
* Calcular o novo salário de acordo com a faixa salarial
* Exibir o valor atualizado após o aumento

### Exercício 3 – Transporte de Colaboradores

* Informar a quantidade de funcionários que utilizarão transporte
* Informar a quantidade de dias úteis
* Calcular o custo mensal do transporte baseado na tabela de preços
